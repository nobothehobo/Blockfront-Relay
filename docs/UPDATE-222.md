# 2.22 — Bassline

The user-approved bass-driven tracks Rocket Power and Exit the Premises by Kevin MacLeod replace the four Eric Skiff chiptune cues, joined by District Four and Cipher. Menus start with Rocket Power; matches start with Exit the Premises. Each playlist rotates all four tracks. The files use edited 90–120-second game cues, with normalization, fades and stereo MP3 compression. Exact titles, creator, ISRC/source links, CC BY 4.0 license and modifications are in the menu/pause credits, copied video credits, shipped attribution notice and [per-track provenance](../assets/music/action-manifest.json). Old chiptune files are removed from the current build, recoverable from Git history; prior credits are retained as historical documentation.

These are licensed alternatives chosen for their bass, drums and electronic groove, not the original Ace of Spades recordings or a claim of an exact musical match. The original soundtrack is not bundled.

All four music recordings now travel in the content-hashed game code, like the already packaged 46 effects. A source resolver creates one cached audio/mpeg Blob URL per track for native media playback. No separate /api/audio/ fetch is needed in the production client, avoiding the cross-version 404 path observed in live logs. MP3s are not duplicated in the Worker asset table. Songs are not decoded into whole-track PCM buffers. Separate volume/mute, gesture unlock, menu/game fades, combat ducking and hidden-tab parking remain in place.

Gun recordings, reloads and explosions are unchanged per the user's revised preference. Existing directional panning, distance attenuation, cover filtering, bounded simultaneous voices and quiet echo remain. Jet start/loop/stop now adapt qubodup's CC0 jet-engine test recording, with crossfaded steady thrust and envelope-shaped activation/deactivation (not recordings of actual ignition or a wearable jetpack). Two distinct Ephisus CC0 boxing-target impacts replace vocal death grunts. Death triggers one impact, not a second fall sound layered over it. Separate generic fall cues remain.

Verification includes exact-byte local Blob tests, playlist rotation, credit/source hash checks, all sample playback tests, TypeScript and hosted builds. Browser control and physical Safari listening are unavailable; final audible playback/mix remains unverified on the user's device. The larger self-contained main download is an intentional delivery-reliability tradeoff.
