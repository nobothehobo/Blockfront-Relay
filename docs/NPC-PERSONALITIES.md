# 2.12.1 — NPC personalities

**2.13.1 correction:** automatic combat cover construction described below was removed. Bots now use existing terrain, retreats and digging; players retain construction. The original release notes below describe historical behavior, not the current building policy. The cover regression now verifies repeated pressured decisions never request construction.

Bots derive a stable profile from their ID and map seed. Skill and tactical style are independent: the distribution weights rookies at 30%, regulars at 50%, and veterans at 20% across hash buckets, not an exact quota in each small room. All tiers retain noticeable error; health, damage, weapon spread and server validation are unchanged.

- Reactions vary roughly 0.28–0.83 seconds. Aim observations update at 0.18/0.28/0.40-second intervals, rather than tracking the opponent's exact current position at every decision. Moving targets can outrun that observation. Aim has a sustained side offset and drifting error, amplified while airborne or recently damaged. Veterans remain threatening but are not perfectly accurate.
- Losing sight preserves only the last observed position. A visible reacquisition requires a fresh reaction delay. Squad reports permit investigating a recent reported location, not firing through walls or following unseen movement. Objective positions remain shared knowledge, as before.
- Assault players close distance sooner; flankers approach offset positions and strafe more; guards hold longer ranges with less strafing; non-assault players are more willing to fortify immediately after damage. Existing defender, carrier, escort, retreat, resupply, digging and zombie-breach rules remain intact.
- Strategic route choices combine individual lane preference, travel cost and teammate congestion. A chosen lane remains stable while the objective stays put, avoiding rapid route switching. Local navigation still reacts to terrain edits, unsafe drops, obstructions and stuck movement. There are only three major lanes, so bots can still share routes and choke points.
- Exposed, pressured humans can briefly switch to Blocks and construct the existing six-block cover kit. The normal terrain ray, support, range, protected-base, player occupancy, resources, cooldown and replication checks all apply. Nearby teammates avoid simultaneous fortification attempts; each builder has an 8–14-second decision cooldown. Zombies never build. This is defensive cover, not unrestricted autonomous fortress construction.

`tests/bot-variety.test.ts` checks deterministic profile variety, genuine moving-target misses, accuracy differences, occluded observation/reaction, authoritative replicated cover/resource accounting and multiple generated-map approach lanes. Existing AI tests continue checking routing, retreats, wall digging, cooperative objectives, burst pauses and melee-only zombies. The production on-device Worker integration also runs these updated bots.

No proprietary assets/code are used. This is a bounded behavioral approximation, not human-level AI. Browser QA was unavailable in the current managed environment; physical iPad performance and difficulty feel still require playtesting. Previously saved online brains lazily acquire the new optional observation fields; a fresh round or new practice session is recommended for consistent comparison.
