# Frontline Edition main menu

The menu takes its direction from the older voxel combat game's large block-letter title, field-colored button stack and character/battlefield presentation. Reference: https://www.mobygames.com/game/59987/ace-of-spades/screenshots/windows/801497/. The artwork and interface are original to Blockfront Relay; no Ace of Spades assets are incorporated.

The original transparent title asset is `client/public/branding/blockfront-relay-logo.png` (1983 × 793 RGBA). It was created with the built-in image-generation tool, not the CLI, then copied into the versioned project. The exact production prompt was:

> Use case: logo-brand. Create an original finished transparent-background title logo for the voxel combat game BLOCKFRONT RELAY, inspired by chunky 2012 military construction game title lettering like Ace of Spades. Exact text only: "BLOCKFRONT" on the upper line and "RELAY" on the lower line. Keep all letters spelled exactly, highly legible even at 300px wide. Bold square-cut, stepped, extruded voxel lettering; warm weathered ivory face with charcoal/steel-grey block extrusion and restrained chipped pixel edges, lower RELAY lettering on a muted construction-orange plate with subtle black/yellow hazard ends. Compact stacked horizontal silhouette around 2.5:1, orthographic slight three-quarter depth, sharp clean outlines and restrained shading. Original small angular relay-flag symbol integrated at one end, not a playing-card spade. Looks like a professionally art-directed old PC game title, not a shiny modern esports badge. No background scene, no frame around the entire image, no characters, no weapons, no additional words, no glow, no gradients in the backdrop. True transparent background, generous clean transparent margin. This is the actual main-menu logo asset for Blockfront Relay, not a mockup.

The backdrop is the actual game renderer. A display-only `MenuScene` uses the existing class body and held equipment, with no room/player authority or simulation. The selected-class model changes only when the selection changes; old display resources are disposed. It hides in portrait and follows reduced-motion preferences. Responsive field-terminal controls retain the existing action IDs and menu workflows. Callsign is a compact header field; connection information has its own panel. Credits are available before and during a match.
