# 2.21 — Arcade Frequency

The active soundtrack is now Eric Skiff's licensed 8-bit/chiptune music: A Night Of Dizzy Spells and Underclocked (underunderclocked mix) for menus; Chibi Ninja and Jumpshot for matches. Four normalized/faded 112–120-second MP3 cues replace all six previous synthwave/cinematic cues. Old music files are removed from this build (recoverable in Git history); historical source credits remain in documentation. Exact artist-requested credit lines, creator/source/license links and edit notes appear in Music & credits, copied video credits, shipped notices and the per-file manifest. CC BY 4.0 explicitly permits this use. See [current music provenance](../assets/music/ATTRIBUTION.md).

Gunfire continues to use the separately recorded AK-47, PPSh, Benelli Nova and Savage firearm reports, with weapon-specific reload/action samples and recorded blasts. Their mix is raised so the transient reports are more distinct. Jetpack ignition, steady thrust and shutdown now adapt real stationary blowtorch recordings by Joseph SARDIN under CC0 rather than a Doppler takeoff effect. This is recorded combustion foley adapted for a fictional jetpack, not a claim of an actual wearable jetpack recording. Source/archive mappings, exact excerpts, processing and credits are preserved in [SFX provenance](../assets/sfx/ATTRIBUTION.md).

Safari can use an ambient category for Web Audio that respects the ringer mute switch while HTML music is audible. WebKit's engineer documents the playback category at https://bugs.webkit.org/show_bug.cgi?id=237322#c6. After a trusted gesture, the game feature-detects and requests navigator.audioSession.type=playback. Repair / retry audio refreshes the category through auto/playback and resumes/retries the existing context/recordings. Unsupported implementations remain functional and show older-Safari Silent Mode guidance. This is a plausible device-specific silence fix, not proof of the user's exact cause. No microphone, recording or device permission is requested. Normal master/effects controls remain authoritative.

Practice and online joins now give effects up to five seconds to finish loading before starting; errors do not permanently block a match. A menu badge shows effects activation/loading/ready/failure and opens Settings. Sample playback diagnostics and recording-only previews remain available. Physical iPhone/iPad playback and subjective sound balance still need confirmation; browser QA is unavailable in this managed environment. All 196 automated tests pass, covering category feature detection/repair, preparation gating, sample decoding/routing, jet loop reuse and playlist/credit checks. TypeScript and hosted build pass. All 46 production WAV API responses match shipped bytes; all four music API routes return correct range data. No physical listening or rendered-browser verification is claimed.
